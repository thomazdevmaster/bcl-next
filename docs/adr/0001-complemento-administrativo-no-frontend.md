# Calcular a pendência administrativa no frontend

O indicador de complemento administrativo será calculado no frontend a partir das contas e pessoas recebidas pelos endpoints existentes, usando as regras atuais de cadastro e perfis. A issue não altera o backend nem adiciona campo ou endpoint: essa opção mantém a mudança no escopo frontend solicitado, com estado neutro quando os dados não puderem ser verificados; uma conta sem pessoa vinculada continua sendo uma pendência.
